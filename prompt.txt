ROLE
You are a senior front-end architect and UI/UX designer. Build a complete, production-quality corporate website for "Datanest Technology", a global IT services and consulting company (positioning similar to TCS, Wipro, Infosys, Accenture). The site must look enterprise-grade, trustworthy and modern, with polished scroll animations and hover effects.

CONSTRAINTS
- Frontend only. NO backend, NO database, NO real API calls.
- The Contact Us form must FEEL fully functional: validate, show a loading state, wait ~1.5 seconds (simulated), then show a success message. Nothing is actually sent.
- Use placeholder but realistic, professional content. Do not use real client logos or copyrighted material. Use simple SVG icons, abstract gradients and generated SVG illustrations. If you use stock images, use reliable free sources and always provide a graceful fallback.

TECH STACK
- React 18 + Vite + TypeScript
- Tailwind CSS (custom theme tokens)
- Framer Motion for scroll-reveal, page transitions, hover and micro-interactions
- React Router v6 for multi-page routing
- Lenis (or similar) for smooth scrolling
- lucide-react for icons
- react-countup (or custom hook) for animated stats
- Swiper or embla-carousel for testimonials/logo marquee
- react-hook-form + zod for form validation
- sonner or react-hot-toast for notifications

- Smooth page transitions between routes (AnimatePresence).
- Hover effects: card lift and shadow, gradient border glow, icon rotation/scale, animated underline links, button shine/ripple, magnetic CTA button, image zoom with overlay.
